## Projeto - Formulário
Objetivo do projeto: criar um formulário utilizando o React e Node.js.

## Requisitos

* Conferir a versão do Node.js 24.19.0 ou superior: node -v
* Conferir se está instalado o npx: npx -v

## Como rodar o projeto baixado

Instalar todas as dependências indicadas pelo package.json.
```
npm install
```

## Sequência para criar o projeto

Criar o projeto com React e Next.js. O ponto "." indica que deve ser criado no próprio diretório.
```
npx create-next-app@latest .
```

## Rodar o projeto React.

```
npm run dev
```

Acessar no navegador a URL.
```
http://localhost:3000
```
